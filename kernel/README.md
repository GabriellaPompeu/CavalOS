🐎 CavalOS

Um pequeno sistema operacional desenvolvido em C e Assembly, com foco educacional e no aprendizado dos fundamentos de sistemas operacionais e arquitetura de computadores.

📌 Sobre o projeto

O CavalOS é um projeto acadêmico desenvolvido para explorar, na prática, conceitos como:

- Bootloader e processo de inicialização
- Kernel
- Interrupções
- Gerenciamento de hardware
- Arquitetura x86
- Programação de baixo nível
- Compilação e linkedição de um sistema operacional
